# Студентський додаток

## Опис проєкту

**StudentApp** — навчальний проєкт студентського додатка, створений у межах навчальної роботи. Репозиторій містить матеріали та файли проєкту, які використовуються для демонстрації структури й роботи застосунку.

## Встановлення

1. Клонувати репозиторій:
   ```bash
   git clone https://github.com/annasacuk27-cmd/StudentApp.git
   ```
2. Відкрити папку проєкту на комп'ютері.
3. Відкрити проєкт у відповідному середовищі розробки.
4. Запустити проєкт.

## Використання

Після відкриття проєкту можна переглянути його файли, структуру та запустити застосунок у середовищі розробки.
